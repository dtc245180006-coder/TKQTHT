# TKQTHT — Quản lý đặt phòng khách sạn

Mã ứng dụng nằm trong thư mục [hotel-booking](hotel-booking/). Trên Ubuntu đã cài Docker Engine và Docker Compose, cài nhanh bằng `cd hotel-booking && bash deploy/install-ubuntu.sh`. Xem [hướng dẫn cài đặt và sử dụng](hotel-booking/README.md).

Kho giữ mã ứng dụng và cấu hình triển khai; đã loại bỏ bộ kiểm thử, báo cáo và ghi chú phát triển. File môi trường, bí mật, dữ liệu khách, bản sao lưu và kết quả chạy không được đưa lên Git.
